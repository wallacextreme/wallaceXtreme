## 👨‍💻 Sobre Mim

Sou graduado/estudante em **Análise e Desenvolvimento de Sistemas**, atuando na construção de software robusto do front ao back-end. Minha abordagem técnica prioriza **resiliência de dados**, **arquitetura limpa**, **performance** e **autonomia operacional local** através de sistemas *offline-first*.

Além do desenvolvimento web convencional (JavaScript, TypeScript, React e Node.js), projeto aplicações desktop multiplataforma com **Tauri** e desenvolvo engines e mecânicas de jogos utilizando **Phaser 3**, **Three.js** e padrões orientados a eventos e ECS (*Entity Component System*). Emprego Inteligência Artificial avançada como ferramenta de engenharia para aceleração de testes, modelagem arquitetural e análise estática de código.

## 🎯 Áreas de Atuação

- 🌐 **Engenharia Web Full Stack**: Aplicações reativas, consumo e design de APIs REST, interfaces modulares e componentização.
- ⚡ **Offline-First & PWAs**: Persistência transacional com `IndexedDB` (`idb`), estratégias de cache, migrations estruturadas e mecanismos de sincronização.
- 🖥️ **Aplicações Desktop**: Criação de binários nativos ultra-leves e seguros utilizando **Tauri** integrado ao ecossistema web moderno.
- 🎮 **Desenvolvimento de Jogos**: Arquiteturas em TypeScript e Vite para motores 2D/3D (Phaser 3 e Three.js), máquinas de estado, sistemas de diálogo e inventário.
- 🧪 **Engenharia de Qualidade**: Automação de testes unitários e de integração com **Vitest** e **Jest**, validando regras de domínio críticas.
